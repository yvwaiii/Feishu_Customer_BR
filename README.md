# 飞书整体使用情况回顾 Skill

当前版本：`2.5.0`

用于生成客户主租户近 180 天飞书整体使用情况回顾，包括 C360/Aeolus 数据提取、七模块洞察分析、飞书画板和回顾文档。

![画板预览](assets/board-preview.png)

## 安装

将仓库内容复制到工作区：

```text
.trae/skills/customer-business-review/
├── SKILL.md
├── README.md
└── references/
```

也可从 GitHub Releases 下载 `customer-business-review-skill.zip`，解压至 `.trae/skills/`。

## 调用场景

当需要准备客户 BR、飞书使用复盘、主租户近 180 天使用分析或数据洞察画板时调用。

## 交付范围

本 Skill 只生成：

1. 客户与主租户识别；
2. C360 与 Aeolus 数据提取；
3. 七模块数据洞察画板；
4. 飞书整体使用情况回顾文档。

到七模块使用情况回顾结束，不生成案例、服务计划、场景共创、交互卡片或会后更新。

## 七模块

1. 即时协同；
2. 会议协同；
3. 内容沉淀；
4. 多维表格；
5. 知识管理；
6. AI 赋能；
7. 服务台。

知识管理必须独立，不能并入 AI 赋能；内容沉淀不能替代知识管理。

## 画板设计

- 深蓝黑渐变背景；
- 七个模块采用单列通栏布局，每个模块独占一行；
- 卡片内横向排列 3～5 个核心指标；
- 每行底部使用一句价值总结收束；
- 标题统一为 `01｜统一协同底座、工作入口稳定`，序号后使用全角 `｜`；
- 禁止使用白色圆角方块包裹单字或缩写；
- 图标优先使用无底框线性 SVG 矢量图标，也可以不使用图标；
- 数据标签使用灰蓝色，数据值使用大号白色，单位弱化；
- 每行数据区严格划分为 5 个等宽列，七个模块复用相同列中心点；
- 指标名称和指标值在列内居中，并共享同一垂直中心轴；
- 单位写入指标名称，例如 `自动化运行数（万次）`，数值区只保留纯数字；
- 底部保留独立数据口径卡。

## 完整性要求

- 画板每模块展示 3～5 个关键指标；
- 正文展示所有有效核心指标；
- 生成前建立 coverage matrix；
- C360 最新快照与 Aeolus 180 天累计、日均数据分开标注；
- 任一有效核心字段未展示时，不得标记交付完成；
- 飞书画板写入后必须导出预览，检查文字溢出、节点重叠、颜色和整体比例。

## 洞见要求

- 时间口径必须写 `近 180 天`，不能写“半年”“近半年”或“6 个月”；
- 每条洞见至少组合两个指标或包含一个派生指标；
- 优先计算日均量、单次均值、产品 DAU 占比、DAU/WAU 和渗透率差；
- 派生指标保留一位小数，并说明参与判断的原始数值；
- 洞见必须揭示规模、覆盖、结构、粘性或供需关系；
- 数据计算在后台完成；画板和正文的洞见句不重复上方已展示的指标或数值；
- 洞见只保留结构判断、阶段判断、覆盖差距或使用特征；
- 禁止用“高效流转、价值显著、持续提升”等口号替代数据判断。
