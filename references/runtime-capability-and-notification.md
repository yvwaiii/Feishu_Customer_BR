# 运行能力检测与用户提醒

## 启动时一次性预检

在查询客户前，同时检查：

1. `lark-c360` 是否安装、环境和登录是否可用；
2. 飞书文档创建和画板读写能力；
3. 是否存在可调用的浏览器工具；
4. 是否存在可操作用户 Chrome 的外部浏览器能力。

不要等到生成中途才逐个暴露权限问题。

## 飞书权限

- 缺少文档或画板权限时，使用当前 Agent 的统一授权能力申请缺失 scope。
- 禁止在 Skill 中运行交互式 `lark-cli auth login` 代替统一授权。
- 用户同意后立即重试原请求；拒绝后停止交付物创建并说明缺少的能力。

## Aeolus 浏览器能力分级

### A. Agent 内置浏览器可用

按 [Aeolus 浏览器自动化手册](aeolus-browser-runbook.md) 自动打开、登录交接、回填和取数。

### B. 用户 Chrome 自动化可用

优先使用外部浏览器能力打开固定网址，复用用户 Chrome 中已有的 ByteDance SSO 登录态。页面出现登录或验证码时，把浏览器控制权交给用户；用户完成后自动继续。

### C. 无任何浏览器自动化能力

不得声称可以直接使用 `lark-cli` 或飞书 OAuth token 调用 Aeolus。实测该看板访问链路是 ByteDance SSO，飞书 OpenAPI 授权与 Aeolus Web 会话不是同一认证体系。

此时向当前 CSM 发送消息或在当前对话明确提醒：

> 当前 Agent 没有可操作浏览器，暂时无法自动回填 Aeolus。请打开固定看板，使用飞书/ByteDance 账号完成登录，填入 F 码并导出当前 180 天与前 180 天数据；把导出文件发回后，我会自动继续。若 Agent 支持浏览器插件，也可以启用后重试。

固定网址：

`https://data.bytedance.net/aeolus/pages/dashboard/1014743?appId=1161&sheetId=1247624`

可接受降级输入：

- Aeolus CSV/XLSX 导出；
- 含完整表头和筛选条件的截图；
- 用户确认过的两期指标表。

没有 Aeolus 数据时，只允许生成“预分析”，不得生成正式 BR 或把 C360 单源结果冒充完整洞见。

## 需要用户操作的阻塞点

以下情况必须提醒并暂停相关步骤：

- C360 未登录或设备校验需要用户处理；
- 客户无法唯一匹配；
- 主租户或 F 码无法确认；
- Aeolus 首次 SSO、验证码或权限申请；
- 无浏览器能力且没有 Aeolus 导出；

提醒内容必须包括：

1. 需要用户做什么；
2. 为什么需要；
3. 完成后 Agent 会从哪一步继续；
4. 不操作会缺少什么，不使用笼统的“执行失败”。

## 非阻塞问题

以下情况记录并继续：

- 某个动态数据模块无有效数据；
- C360 diagnostics 日志无法写入但业务命令成功；
- 对比期无法稳定取得。

客户可见回顾不展示技术错误；在口径说明和当前对话中展示影响范围。
