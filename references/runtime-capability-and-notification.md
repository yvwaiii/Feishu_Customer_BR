# 运行能力检测与用户提醒

## 按需能力检查

禁止启动时枚举全部能力。仅在对应分支即将执行时检查一次：

1. 当前输入不足且需要 C360 时，检查 `lark-c360` 安装、环境和登录；
2. 本地 renderer/auditor 通过且准备创建交付物时，检查飞书文档和画板权限；
3. 用户明确要求增强版或 C360 快照已就绪时，至多探测一次可用浏览器。

不得读取无关帮助文档、枚举所有工具，或为快照模式预先探测 Chrome。

## 飞书权限

- 缺少文档或画板权限时，使用当前 Agent 的统一授权能力申请缺失 scope。
- 禁止在 Skill 中运行交互式 `lark-cli auth login` 代替统一授权。
- 用户同意后立即重试原请求；拒绝后停止交付物创建并说明缺少的能力。

## 运行模式选择

### 无内网浏览器环境

出现以下任一情况时，直接选择 **C360 快照模式**：

- `data.bytedance.net` DNS、TLS 或 SSL 连接失败；
- 运行环境不在 ByteDance 内网；
- 只有沙箱浏览器，且不能访问内网站点；
- 无法接管用户电脑上的已登录浏览器；
- 当前产品为 Aily 智能伙伴或其他不提供内网浏览器的云端 Agent。

只探测一次，不用不同浏览器或网络工具反复访问同一内网地址。不得要求 Aily 接管本地 Chrome。

C360 七模块数据完整但 Aeolus 十项未齐时，只能继续生成草稿回顾与画板，并标注：

> 数据口径：C360 最新使用快照。本次未接入 Aeolus，因此不包含近 180 天累计、日均、趋势和对比期。

### 可访问 Aeolus 的自动化环境

TRAE、Codex 或其他 Agent 只要具备浏览器自动化能力，且该浏览器能访问 ByteDance 内网，就优先使用增强模式。不要因为产品名称未知而跳过浏览器能力探测。

#### Agent 内置或模拟浏览器可用

按 [Aeolus 浏览器自动化手册](aeolus-browser-runbook.md) 自动打开、登录交接、回填和取数。

#### 用户 Chrome 自动化可用

优先使用外部浏览器能力打开固定网址，复用用户 Chrome 中已有的 ByteDance SSO 登录态。页面出现登录或验证码时，把浏览器控制权交给用户；用户完成后自动继续。

### 用户明确需要 180 天增强数据

不得声称可以直接使用 `lark-cli` 或飞书 OAuth token 调用 Aeolus。实测该看板访问链路是 ByteDance SSO，飞书 OpenAPI 授权与 Aeolus Web 会话不是同一认证体系。

仅当用户明确要求近 180 天累计、日均、趋势或对比期，且当前环境无法访问 Aeolus 时，再请求用户提供导出：

> 当前运行环境无法访问 ByteDance 内网 Aeolus。我可以先基于 C360 生成最新使用快照版；如需近 180 天累计、日均、趋势和对比期，请导出 Aeolus 数据后发回，我会升级为增强版。

固定网址：

`https://data.bytedance.net/aeolus/pages/dashboard/1014743?appId=1161&sheetId=1247624`

可接受降级输入：

- Aeolus CSV/XLSX 导出；
- 含完整表头和筛选条件的截图；
- 用户确认过的当前期-only 或两期指标表。

没有 Aeolus 数据时不得把 C360 快照冒充近 180 天分析，但可生成口径清晰的正式 C360 快照版。

## 需要用户操作的阻塞点

以下情况必须提醒并暂停相关步骤：

- C360 未登录或设备校验需要用户处理；
- 客户无法唯一匹配；
- 主租户或 F 码无法确认；
- 用户明确要求增强模式，但 Aeolus 首次 SSO、验证码或权限申请未完成；
- 用户明确要求增强模式，且无浏览器能力也没有 Aeolus 导出；

提醒内容必须包括：

1. 需要用户做什么；
2. 为什么需要；
3. 完成后 Agent 会从哪一步继续；
4. 不操作会缺少什么，不使用笼统的“执行失败”。

## 非阻塞问题

以下情况记录并继续：

- 某个动态数据模块无有效数据；
- C360 diagnostics 日志无法写入但业务命令成功；
- 对比期无法稳定取得。

对比期无法稳定取得时，只要当前期与指标完整，仍进入增强模式并展示当前值；明确“未提供对比期”，不生成新的导出邀请。
- Aeolus 因运行环境限制不可访问，但 C360 七模块数据完整。

客户可见回顾不展示技术错误；在口径说明和当前对话中展示影响范围。
