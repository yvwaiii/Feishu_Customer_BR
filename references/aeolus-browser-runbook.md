# Aeolus 浏览器自动化手册

固定看板：

`https://data.bytedance.net/aeolus/pages/dashboard/1014743?appId=1161&sheetId=1247624`

## 已验证流程

### 1. 打开与登录

1. 直接打开固定网址。
2. 如跳转 ByteDance SSO，将浏览器交给用户完成登录。
3. 返回后确认页面标题为 `CSM-飞书提效价值计算器`。
4. 关闭首次使用提示，不影响后续查询。

### 2. 回填企业编码

1. 找到 `企业编码（F/L码）` 筛选器。
2. 打开下拉框，定位 `查找或输入选项` 输入框。
3. 输入完整 F 码。
4. 只选择与输入完全一致的候选项。
5. 验证筛选器标题已显示该 F 码。

禁止使用模糊候选、客户名称、租户名称、account id 或 tenant id。

### 3. 设置滚动 180 天

看板默认数据截止日通常是最近可用数据日，不保证等于当前自然日。以日期筛选器默认结束日作为 `data_end`，并据此计算：

- 当前期开始日：`data_end - 179 天`；
- 当前期结束日：`data_end`；
- 对比期结束日：`当前期开始日 - 1 天`；
- 对比期开始日：`对比期结束日 - 179 天`。

稳定操作：

1. 打开日期筛选器。
2. 先切到“动态日期”，再切回“固定日期”，使开始、结束日期都重置为最近可用数据日。
3. 记录默认结束日期。
4. **只修改开始日期**为 `data_end - 179 天`，不要再次编辑结束日期。
5. 验证页面筛选器标题显示精确的 `开始日 ~ 结束日`。

该控件是自定义双日期选择器。直接编辑“结束日期”可能误改开始日期；不要连续向两个文本框写值。设置失败时按上述“动态日期 → 固定日期 → 只改开始日期”流程重置。

### 4. 启动并验证查询

1. 点击刷新。
2. 等待查询请求完成。
3. 验证：
   - 企业编码筛选器显示目标 F 码；
   - 统计时间显示精确 180 天范围；
   - 数据区出现 `自助查询` 表格及指标值；
   - 网络中出现 Aeolus `vizQuery/query` 请求。
4. 页面是宽画布时，必要时向左滚动，再向下滚动到表格。
5. 保存查询条件和全部指标。

### 5. 对比期

1. 按相同流程重置固定日期。
2. 以当前期开始日前一天为对比期结束日。
3. 只修改开始日期为对比期开始日；如默认结束日不是目标对比期结束日，优先使用日历点选完成范围。
4. 若自动化无法稳定设置对比期结束日，不得猜测同比：
   - 保留当前期数据；
   - 标记同比未获取；
   - 继续生成不含同比的指标卡。

## 数据读取

- 读取表格中的指标分组、指标名称、值和单位。
- 不根据行位置猜测字段名。
- 表格未完全加载时继续等待，不截取半成品。
- 相同指标重复出现时保留分组上下文。
- 无法通过 DOM 获取数据时，可使用页面截图识别，但必须逐项核对标题和数值。

## 运行验证清单

每次执行时确认：

- 使用当前客户主租户的 F 码精确搜索；
- 租户显示名与 C360 所属客户关系已核对；
- 日期范围为以最近可用数据日结束的滚动 180 天；
- 刷新后 `自助查询` 表格已完整加载；
- 可读取消息、会议、日程、文档和多维表格等目标指标；
- 当前查询结果未混入上一次筛选条件或其他租户数据。
