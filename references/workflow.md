# 执行流程

## 1. 前置门槛

1. 先按 [环境检测、安装与恢复](bootstrap-and-recovery.md) 检测并自动补齐 `lark-c360`，并按 [运行能力检测与用户提醒](runtime-capability-and-notification.md) 一次性检查飞书权限和浏览器能力。
2. 使用 `customer_name` 在 C360 只读匹配客户；若输入 `tenant_fcode`，先精确反查租户及所属客户。
3. 无唯一客户结果时停止，让 CSM 补充或选择。
4. 获取该客户下全部关联租户及 DAU，选 DAU 最高者为唯一主租户。
5. 获取该主租户 F 码。主租户或 F 码缺失时停止。

## 2. 日期计算

- 当前周期：以 Aeolus 日期筛选器显示的最近可用数据日为结束日，向前滚动 180 天，包含明确的起止日期。
- 同比周期：紧邻当前周期之前的 180 天，不重叠、不留空档。
- 先在 Aeolus 确认最近可用数据日，再将同一组当前周期起止日期传给 C360；不得分别使用“近半年”等模糊口径。

## 3. Aeolus 回填

指定看板：

`https://data.bytedance.net/aeolus/pages/dashboard/1014743?appId=1161&sheetId=1247624`

1. 把 C360 返回的主租户 F 码回填为看板查询条件。
2. 按 [Aeolus 浏览器自动化手册](aeolus-browser-runbook.md) 设置滚动 180 天，并将该日期范围同步给 C360。
3. 启动查询并确认成功。
4. 优先使用 Agent 内置浏览器；没有时使用可操作用户 Chrome 的外部浏览器能力。
5. 无任何浏览器能力时，提醒用户打开固定网址并导出两期数据；收到 CSV/XLSX、完整截图或已确认指标表后继续。
6. 禁止用客户名称、租户名称或其他标识替代 F 码。
7. 回填或启动失败且用户未提供导出时停止正式 BR，并说明失败环节。

## 4. 数据收集

仅在 C360 主租户/F 码获取及 Aeolus 回填成功后执行：

- C360 客户、主租户及七模块固定使用指标；
- Aeolus 飞书业务使用指标及板块数据；
- coverage matrix 所需字段。

不搜索群聊、会议、功能、案例或行业资料。

## 5. 分析与产出

1. 按业务板块关联全部指标。
2. 生成 coverage matrix，检查有效核心字段是否完整。
3. 七模块各选择 3～5 个画板指标，同时保留正文完整数据。
4. 创建一张数据洞察画板和一份“飞书整体使用情况回顾”文档。
5. 回读画板和文档；画板出现占位图、空白、错色或结构异常时，新建画板重做。
6. 校验通过后结束，不继续生成任何后续章节或自动化。
